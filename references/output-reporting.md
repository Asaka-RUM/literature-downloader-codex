# 中文报告与实际文件

交付 `下载报告.html`；指定 `--pdf` 时使用 ReportLab 本地生成 PDF，不启动任何浏览器。缺少 PDF 依赖时保留 HTML 并明确报告原因。

只有 `success_pdf` 进入成功 PDF 清单；它描述结构校验，不保证题名、DOI、正文或结论正确。`saved_html_unverified/xml_unverified` 和旧 `success_html/xml` 均作为待核验内容处理。

高、中、低优先级忠实反映初筛，排除项不进入高或中优先级。下载状态与相关性是独立维度。期刊指标须附年份和来源，未经核验不写成已确认。

`downloaded_fulltexts/` 与 `已下载全文/` 保存结构有效 PDF；`unverified_content/` 与 `待核验内容/` 保存待核验网页/XML。面向用户优先给中文路径。

原始配置、候选表和日志留在原位置，内部目录仅作非破坏性快照。不为美化目录移动续跑必需数据。
